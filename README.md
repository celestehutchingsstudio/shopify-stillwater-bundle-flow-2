# Stillwater · Build Your Bundle · Flow 2

Coded prototype for the merchant side of the Stillwater "Build Your Bundle" Shopify case study.

- **Flow 2 · Mark sets up the bundle page**: open `index.html` in a browser. Mark works in the Shopify theme editor: he opens the build-your-bundle page template, adds the Build Your Bundle section, sets the heading and both bundle sizes with their rewards, adds Category blocks for Fragrance, Skin and lip care and Accessories, picks a collection for each, checks the mobile preview and saves. Saving shows that the page is live.
- **iPhone version**: open `mobile.html` to see the same prototype as the Shopify mobile editor inside an iPhone 15 frame. The layout also switches to the mobile editor on its own once the screen is narrow.

Use the controls bar to switch between Desktop and iPhone, jump to any designed screen (1–9) or restart. The layout follows `Designs · Flow 2` in the Figma file *Shopify Build Your Bundle · Style guide*: Shopify admin foundations for the editor, the Stillwater style sheet for the storefront preview.

What works: the page selector, Add section search, live editing of every setting (the preview updates as you type), Add Category, header image Change and Remove, the collection picker, reordering Category blocks (drag in the template tree, or Move up and Move down in the block's ⋯ menu), removing blocks, undo and redo, the desktop and mobile preview toggle, and Save. In the preview you can switch bundle sizes and add products to the bundle.

`assets/` holds the product photos and category banners from Flow 1. No real store, card or personal data is used.
